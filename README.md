# Biltum

Bring your saved Biltum job into Claude or ChatGPT without attaching Job Files. Find a job, read its scan narration, measurements, photos and documents, and consult its saved Company Profile. Ask to save a scope correction as a job note or rename a scan. Original capture evidence stays intact.

Connect Biltum and sign in through JobTread using your existing Biltum account. Then ask, for example, “Summarize the Biltum scans for job #66” or “Save a note on that job: keep the existing vanity.” Update actions require Biltum update access and your existing job permissions.

For budget writing, also connect JobTread's official connector. Ask to write the budget for the exact job using its Biltum scans. Biltum supplies the saved job evidence and the same budget and measurement-report instructions used in Job Files. The separate JobTread connector performs authorized budget changes and reads back their result. The workflow includes a room-by-room measurement table and an attached measurement-report PDF when the chat has working file-generation tools. Unlinked projects receive a company-format draft instead of a JobTread write.

Current authorized customer consultations are read separately from scan files, so their own permissions and deletion state remain effective. Recording times are used when the saved source supplies them; unknown chronology is disclosed. Where supported, original Apple text-model heights/elevations are matched to the saved numerical plan and supplied as optional JSON evidence. Unmatched objects, unsupported models and original video playback remain unavailable; saved images/frames can be read instead. Unsupported files are reported rather than treated as inspected.

The connector sends the requested job evidence and tool results to the chat provider you connect. Its encrypted server state holds the account session used to enforce your current Biltum permissions. Account credentials and private storage access keys are never included in this plugin package or tool results. Disconnect the connection to revoke its Biltum credentials.

Public directory review and publication are pending. Scheduled automatic budgeting is a future feature.
